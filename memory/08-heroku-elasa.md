# Heroku-elasa + حوزه‌های محیط‌زیست و اجتماعی

منبع: https://github.com/Heroku-elasa?tab=repositories

دو حوزه جدید برای پروژه‌هایی که در ده حوزه غرفه جا نمی‌گرفتند:

- **محیط‌زیست / پاکسازی:** امید سبز (کاشت درخت)، EcoSmart پسماند، ورشکستگی آبی ایران، ecoAI، پیش‌بینی آتش جنگل
- **اجتماعی:** Civicavita (بشردوستانه — نه CRM غرفه)، جان‌پناه حیوانات، آورا تندرستی/موسیقی، تحلیل مهربانی رسانه

بعضی مخازن همان برند حوزه‌های قبلی‌اند: آرمان، دادگر، املاک، حسابرس استیل‌آنلاین، کاریاب، الکُن، هورتش، رویش.
